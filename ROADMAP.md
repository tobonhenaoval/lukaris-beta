# Roadmap global de LUKARIS

## Beta 0.3 — decisiones estratégicas y seguridad de datos
- [x] Onboarding adaptativo: recomendaciones de módulos por actividad
- [x] Administración dual: empresa individual o grupo con sucursales
- [x] Modelo comercial global: Starter, Growth, Scale y Enterprise (precios de referencia)
- [x] Perfil internacional inicial: país, moneda, idioma y zona horaria
- [x] Exportar/importar respaldo JSON con validación y confirmación
- [ ] Edición/eliminación de registros con confirmación
- [ ] Búsqueda y filtros en todos los módulos
- [ ] Historial del cliente
- [ ] Abonos, saldos y cuentas por cobrar
- [ ] Movimientos de inventario y ajuste de stock

## Núcleo universal
- [ ] CRM, contactos, etiquetas y seguimiento
- [ ] Agenda configurable: citas, reservas, turnos y reuniones
- [ ] Catálogo mixto de productos y servicios
- [ ] Cotizaciones, pedidos, ventas y pagos
- [ ] Operaciones: tareas, proyectos, órdenes y entregas
- [ ] Equipo, roles, permisos y comisiones
- [ ] Reportes configurables y exportación

## Plantillas de industria
Retail y comercio; restaurantes y alimentos; servicios profesionales; salud y bienestar; educación; construcción; automoción; logística; turismo; negocios digitales; y otras actividades configurables.

## Internacionalización pendiente
- [ ] Traducciones completas
- [ ] Zonas horarias reales por empresa y usuario
- [ ] Formatos regionales de fecha, número y dirección
- [ ] Impuestos y documentos fiscales por país
- [ ] Proveedores de pago por mercado
- [ ] Privacidad y retención de datos por jurisdicción

## Plataforma SaaS real (cuando se apruebe backend)
- [ ] Autenticación y multi-tenant
- [ ] Aislamiento de datos entre empresas y sucursales
- [ ] Suscripción y facturación global del SaaS
- [ ] Integraciones: correo, WhatsApp/SMS, calendarios y pagos
- [ ] API, webhooks, auditoría y backups automáticos
